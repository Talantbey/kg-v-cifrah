# Второй рабочий стол за секунду: Win + Ctrl + D

**Хук (первые 2 секунды):** Второй рабочий стол за секунду.

**Проблема:** Работа, учёба и соцсети — всё в одной куче окон.

**Решение:** Виртуальные рабочие столы Windows: Win + Ctrl + D создаёт новый стол, Win + Ctrl + ← / → переключает между столами, Win + Tab показывает все столы (представление задач), Win + Ctrl + F4 закрывает текущий стол — открытые на нём окна переходят на следующий стол.

**Совместимость:** Windows 10 · Windows 11

**Источник:** support.microsoft.com — «Keyboard shortcuts in Windows» (Win + Tab, Win + Ctrl + D, Win + Ctrl + ← / →, Win + Ctrl + F4) и «How to Multitask in Windows» (новый стол через представление задач; при закрытии стола приложения переносятся на следующий доступный стол)

**Пошаговая инструкция:**

1. Нажми Win + Ctrl + D — откроется новый пустой рабочий стол
2. Открой на нём нужные окна
3. Win + Ctrl + ← / → — переключение между столами
4. Win + Tab — показать все рабочие столы (или кнопка представления задач на панели задач → «New desktop»)
5. Win + Ctrl + F4 — закрыть текущий стол; его окна перейдут на следующий стол

**Длительность:** 34.0 с
