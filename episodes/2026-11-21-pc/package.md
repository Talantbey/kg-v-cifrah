# Программа зависла? Ctrl + Shift + Esc → «Снять задачу»

**Хук (первые 2 секунды):** Программа зависла? Закрой её за пару секунд.

**Проблема:** Окно не отвечает, крестик не помогает, компьютер тормозит.

**Решение:** Ctrl + Shift + Esc сразу открывает диспетчер задач; правый клик по зависшему приложению → «Снять задачу» принудительно закрывает его.

**Совместимость:** Windows 10, Windows 11

**Источник:** support.microsoft.com — «Средства настройки системы в Windows» (Ctrl+Shift+Esc, завершение не отвечающих программ); asus.com/ru FAQ 1043921 — «Снять задачу» (Windows 11/10)

**Пошаговая инструкция:**

1. Нажми Ctrl + Shift + Esc — откроется диспетчер задач
2. Windows 10: если окно маленькое, нажми «Подробнее»
3. Найди зависшую программу и кликни по ней правой кнопкой
4. Выбери «Снять задачу» — программа закроется
5. Системные процессы Windows не закрывай

**Длительность:** 31.4 с
