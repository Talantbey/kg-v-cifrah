# Спрячь все окна за секунду: Win + D и Win + L

**Хук (первые 2 секунды):** Спрячь все окна за одну секунду.

**Проблема:** Кто-то подошёл к компьютеру, а на экране открыто личное; сворачивать окна по одному долго.

**Решение:** Win + D показывает и скрывает рабочий стол (повторное нажатие возвращает окна); Win + L блокирует компьютер.

**Совместимость:** Windows 10, Windows 11

**Источник:** support.microsoft.com — «Сочетания клавиш в Windows» / «Windows keyboard tips and tricks»

**Пошаговая инструкция:**

1. Нажми Win + D — все окна свернутся, видно рабочий стол
2. Нажми Win + D ещё раз — окна вернутся на место
3. Уходишь — нажми Win + L, компьютер заблокируется
4. Чтобы вернуться, войди в систему снова

**Длительность:** 30.2 с
