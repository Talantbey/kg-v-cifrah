# Браузер прочитает статью вслух

**Хук (первые 2 секунды):** Пусть браузер сам прочитает тебе статью

**Проблема:** Длинная статья, а читать некогда или устали глаза.

**Решение:** Функция «Читать вслух» в Microsoft Edge озвучивает веб-страницу: сочетание Ctrl + Shift + U запускает и останавливает чтение, также её можно включить через правую кнопку мыши.

**Совместимость:** Microsoft Edge на Windows 10 · 11

**Источник:** support.microsoft.com — «Accessibility features in Microsoft Edge» (4000734): «select and hold (right-click) anywhere on the page and choose Read aloud»; таблица клавиш: «Ctrl+Shift+U — Start or stop Read aloud»

**Пошаговая инструкция:**

1. Открой статью в Microsoft Edge
2. Нажми Ctrl + Shift + U — Edge начнёт читать страницу вслух
3. Или щёлкни правой кнопкой мыши по странице → «Читать вслух»
4. Нажми Ctrl + Shift + U ещё раз, чтобы остановить

**Длительность:** 28.1 с
