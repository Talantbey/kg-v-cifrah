# Буфер обмена с памятью: Win + V

**Хук (первые 2 секунды):** В Windows есть буфер обмена с памятью.

**Проблема:** Скопировал новое — а то, что копировал раньше, пропало.

**Решение:** Сочетание Win + V открывает журнал буфера обмена: в нём последние скопированные тексты и картинки.

**Совместимость:** Windows 10 (с версии 1809), Windows 11

**Источник:** support.microsoft.com — «Использование буфера обмена», «Сочетания клавиш в Windows»

**Пошаговая инструкция:**

1. Нажми Win + V
2. В первый раз нажми «Включить» (или: Параметры → Система → Буфер обмена → Журнал буфера обмена)
3. Выбери нужную запись — она вставится
4. Важное можно закрепить, чтобы оно не пропало

**Длительность:** 26.4 с
