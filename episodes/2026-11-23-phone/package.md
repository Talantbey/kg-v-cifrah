# Поставь Face ID на любое приложение iPhone

**Хук (первые 2 секунды):** Любое приложение на iPhone можно закрыть на Face ID — без сторонних программ

**Проблема:** Даёшь телефон другу или ребёнку — и не хочешь, чтобы открыли переписку, галерею или банк.

**Решение:** В iOS 18 приложение можно заблокировать прямо с экрана «Домой»: удерживаешь значок и выбираешь «Требовать Face ID». Открыть его можно только после Face ID, Touch ID или код-пароля.

**Совместимость:** iPhone с iOS 18 и новее (iPhone XS / XR и новее); некоторые встроенные приложения — Калькулятор, Камера, Часы, Контакты, Локатор, Карты, Команды, Настройки — заблокировать нельзя

**Источник:** support.apple.com — Руководство пользователя iPhone «Lock or hide an app on iPhone» (iph00f208d05) и «Use locked apps with Stolen Device Protection» (125690)

**Пошаговая инструкция:**

1. Найди приложение на экране «Домой» и удерживай его значок, пока не откроется меню
2. Нажми «Требовать Face ID» (на iPhone с кнопкой «Домой» — Touch ID, без них — код-пароль)
3. Подтверди ещё раз «Требовать Face ID» и пройди Face ID
4. Снять блокировку: удерживай значок → «Не требовать Face ID» → подтвердить

**Длительность:** 29.8 с
