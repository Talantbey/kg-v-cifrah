# Вернуть закрытую вкладку за 1 секунду

**Хук (первые 2 секунды):** Случайно закрыл вкладку? Верни её за секунду

**Проблема:** Нужная вкладка закрыта, а сайт уже не найти.

**Решение:** Сочетание Ctrl + Shift + T заново открывает закрытые вкладки в том порядке, в котором их закрыли.

**Совместимость:** Google Chrome (Windows, Linux, Mac) и Microsoft Edge

**Источник:** support.google.com — «Chrome keyboard shortcuts» (157179): «Reopen previously closed tabs in the order that they were closed — Ctrl + Shift + t»; support.microsoft.com — «Microsoft Edge keyboard shortcuts»: «Ctrl + Shift + T — Reopen the last closed tab»

**Пошаговая инструкция:**

1. Нажми Ctrl + Shift + T (на Mac в Chrome: Cmd + Shift + T)
2. Закрытая вкладка откроется снова
3. Нажми ещё раз — вернутся предыдущие закрытые вкладки по порядку

**Длительность:** 30.0 с
