# Эмодзи на компьютере за секунду: Win + .

**Хук (первые 2 секунды):** Эмодзи прямо на компьютере.

**Проблема:** Чтобы вставить смайлик, ищешь его в интернете и копируешь.

**Решение:** Сочетание Win + . (точка) во время ввода текста открывает панель эмодзи; можно искать, просто печатая слово.

**Совместимость:** Windows 10, Windows 11 (GIF — Windows 11)

**Источник:** support.microsoft.com — «Советы и рекомендации по работе с клавиатурой Windows» (раздел «Вставка эмодзи, GIF-изображений и символов с помощью панели эмодзи»)

**Пошаговая инструкция:**

1. Поставь курсор в поле ввода текста
2. Нажми Win + . (точка)
3. Печатай слово — панель найдёт эмодзи
4. Выбери эмодзи мышью — он вставится
5. В Windows 11 в панели также GIF, каомодзи и символы

**Длительность:** 30.9 с
