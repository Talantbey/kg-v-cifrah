# Скриншот за 1 секунду — без программ

**Хук (первые 2 секунды):** Всё ещё делаешь скриншоты через Paint?

**Проблема:** Нужна только часть экрана, а приходится снимать всё и обрезать вручную.

**Решение:** Сочетание Win + Shift + S открывает «Ножницы» (Snipping Tool) прямо поверх экрана.

**Совместимость:** Windows 10, Windows 11

**Источник:** support.microsoft.com — «Use Snipping Tool to capture screenshots»

**Пошаговая инструкция:**

1. Нажми Win + Shift + S
2. Выдели нужную область мышкой (прямоугольник, окно или весь экран)
3. Снимок копируется в буфер обмена — вставь его через Ctrl + V

**Длительность:** 32.4 с
